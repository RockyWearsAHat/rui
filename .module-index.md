# Module Index — updated 2026-08-27

| Path | Purpose | Public Interface | Critical | Notes |
|------|---------|------------------|----------|-------|
| `src/element` | UI element tree—`El<T>` nodes, builders for structure, behavior handlers as state functions. | `El`, `Children`, `Action`, `TextAction` | yes | Core language. No retained widget tree; description rebuilt each frame from state. |
| `src/widgets` | Widget recipes: button, text, title, panel, tabs, draw, etc.—all built from primitives, not variants. | `button`, `text`, `title`, `heading`, `caption`, `code`, `micro`, `figure`, `col`, `row`, `panel`, `tabs`, `draw`, `field`, `meter`, etc. | yes | Type scale (five sizes) named, not numbered. Extensible—custom widgets add to the grammar. |
| `src/style` | Layout and appearance configuration: `Length`, `Radius`, `Tone` (color roles), `Align`, `Justify`, text inheritance. | `Length`, `Radius`, `Tone`, `Align`, `Justify`, `Anchor`, `Axis`, `Face`, `Ink`, `Style` | yes | Roles over values for light/dark mode. Text inherits; layout does not. |
| `src/layout` | Flexbox-like layout engine—stacking, fills, flow wrapping, scroll, layer support in two passes. | `Ctx`, layout functions (internal) | yes | No constraint solver, no absolute positioning. Single-pass measure, single-pass position. |
| `src/paint` | Drawing and event dispatch—one tree walk measures interactions, draws, and routes handlers. | `Painter`, `Visual`, `Deferred` | yes | Handlers run after frame finishes; description borrows state immutably during draw. |
| `src/canvas` | Pixel buffer and drawing primitives: fills, strokes, antialiased rounded rectangles via signed distance fields. | `Canvas`, `Corner`, `Mask` | yes | One format (ARGB) across all platforms. Logical units scaled to device pixels here only. |
| `src/shell` | Event loop, platform window management, font loading, window backends (macOS, Windows, X11, WebAssembly). | `Error`, `LoadedFonts`, `WindowOptions`, `Backend` (trait, internal) | yes | Five methods per backend. No dirty tracking; full frame comparison. Two speeds (animating vs. idle). |
| `src/shell/embedded_fonts` | Embedded font loading from `include_bytes!` data. | `load_embedded_fonts` | yes | Provides fallback fonts built into the binary; used when system fonts unavailable. |
| `src/shell/fonts` | System font loading (macOS, Windows, X11) and font caching. | `load_system_fonts` | yes | Loads fonts from OS, indexes them by `FontId`. Caches loaded glyphs. |
| `src/font` | TrueType parser, glyph rasterizer, text layout with kerning/ligatures support. No complex-script shaping, no hinting. | `Font`, `FontError`, `GlyphId`, `LineMetrics`, `RenderedGlyph` | yes | Covers Latin, Greek, Cyrillic. PostScript outlines refused. Deterministic across platforms. |
| `src/font/outline` | TrueType `glyf` table parsing, outline reading, quadratic B-spline flattening to edges. | (module-private) | yes | Supports implied on-curve points; flattens curves at draw size. |
| `src/font/raster` | Glyph rasterization via scanline algorithm, subpixel positioning, antialiasing. | (module-private) | yes | Coverage via signed distance fields. Four subpixel phases. Size quantization to 0.25px. |
| `src/font/sfnt` | SFNT structure reader: directory, table lookup, character map. | (module-private) | yes | Validates font structure, routes to correct table handlers. |
| `src/text` | Text layout and rendering—measuring and drawing glyphs in `Fonts` cache. Consistent measure/draw paths. | `Fonts`, `FontId`, `TextStyle`, `SUBPIXEL_PHASES`, `SIZE_QUANTUM` | yes | Subpixel positioning (four phases). Glyph cache. Size quantized at 0.25px. |
| `src/app` | Application entry point and event loop orchestration—couples state, view function, shell. | `App`, `run`, `Error` | yes | Rebuilds UI from state each frame. Renders, lays out, draws, dispatches handlers in order. |
| `src/memory` | Interaction state between frames—hover, focus, scroll, caret, animations, keyed by element identity. | `Memory`, `Id`, `Response`, `Caret` | no | No application data stored. Identity derived from element path; `.key()` overrides for reordered lists. |
| `src/input` | Input event abstraction—raw `Event`s folded into immediate-mode `Input` (pointer, buttons, text, keys). | `Input`, `Event`, `Drag`, `Key`, `Modifiers`, `Phase`, `PointerButton` | no | Distinguishes held from newly-pressed. Backends report events; widgets query input. |
| `src/theme` | Color themes, appearance (light/dark), palette, text styles, status hues, spacing. | `Appearance`, `Palette`, `Status`, `Theme` | yes | Small, deliberate palette. Surface is a pair (top/bottom, for subtle shading). One appearance at a time. |
| `src/color` | sRGB color type (8-bit RGBA), blending (straight alpha, non-gamma-corrected for OS consistency). | `Color`, `blend_over` | no | Straight alpha. Blending matches platform compositing (pragmatic, not strict). |
| `src/geom` | Geometry primitives in logical units: `Point`, `Size`, `Rect`, `Insets`. Top-left origin, y-down. | `Point`, `Size`, `Rect`, `Insets` | no | Supporting type. No scaling here; canvas does that. |
| `src/image` | PNG encoding (uncompressed, deflate stored blocks). Writes rendered frames to files. | `encode_png` | no | Utility for screenshot/test output. Uses minimal compression (stored deflate blocks). |
| `src/testing` | Test harness—`Harness` drives real rendering into a buffer with no window. Deterministic synthetic font. | `Harness` | no | Testing double. Uses real layout/paint/font stack. Stepped animations, no clock reads. |
| `src/testing/font` | Synthetic font for deterministic testing—half-em advance per character, measurable ascent/descent. | `test_font` | no | Ensures test widths are round numbers. Same rasterization path as real fonts. |
