EXAMPLE DESCRIPTIONS
================================================================================

LEARNING PATH (Recommended order):

1. COUNTER (examples/counter.rs) — Start here!
   • Simplest possible app: increment/decrement counter
   • Demonstrates: State struct, view function, click handler
   • Build time: ~0.08s
   • Pattern: Perfect for beginners learning the framework

2. SEGMENTED (examples/segmented.rs) — Next step
   • Interactive choice selector
   • Demonstrates: Widget building from primitives, handler patterns
   • Build time: ~0.08s
   • Pattern: Copy and modify template for custom controls

3. METER (examples/meter.rs) — Passive widget
   • Progress bar (read-only, no interaction)
   • Demonstrates: Display-only widgets, pure data flow
   • Build time: ~0.08s
   • Pattern: How to build status displays

4. CALCULATOR (examples/calculator.rs) — Complex state
   • Full four-function calculator
   • Demonstrates: Complex stateful computation, grid layouts
   • Build time: ~0.36s
   • Pattern: Managing calculations, button organization

5. TODO_APP (examples/todo_app.rs) — List management
   • Persistent todo list with add/complete/delete
   • Demonstrates: Vec<T> state, list rendering, custom checkboxes
   • Build time: ~0.36s
   • Pattern: Building list-based applications

6. THEME_SWITCHER (examples/theme_switcher.rs) — Appearance
   • Light/dark mode switching with tone showcase
   • Demonstrates: Segmented control, color theming, responsive UI
   • Build time: ~0.36s
   • Pattern: Building appearance-aware interfaces

REFERENCE EXAMPLES:

7. CONTROLS (examples/controls.rs) — Widget gallery
   • Comprehensive showcase of built-in widgets
   • Demonstrates: All primitive patterns (draw, on_drag, on_key, layers)
   • Build time: ~0.36s
   • Pattern: Reference for all widget patterns

8. GALLERY (examples/gallery.rs) — PNG output
   • Renders UI elements to PNG files (no window)
   • Demonstrates: Headless rendering, appearance switching
   • Build time: ~0.36s
   • Pattern: For CI/CD screenshot generation

PARITY & VERIFICATION:

9. PARITY (examples/parity.rs) — Reference frames
   • Generates native reference frames for WASM comparison
   • Demonstrates: Multi-appearance rendering, image serialization
   • Build time: ~0.36s
   • Pattern: Backend verification workflow

10. SEGMENTED_MODIFIED (examples/segmented_modified.rs) — Copy-paste verification
    • Verifies the "copy and modify" pattern actually works
    • Demonstrates: Pattern validation, example as documentation
    • Build time: ~0.08s
    • Pattern: Proof that examples are accurate templates

SPECIALIZED:

11. ICON (examples/icon.rs) — Icon generation
    • Generates macOS .iconset and .icns icons from code
    • Demonstrates: Advanced drawing, multi-size rendering
    • Build time: ~0.36s
    • Pattern: For app packaging and branding
