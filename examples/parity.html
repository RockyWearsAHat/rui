rui — native / browser backend parity

The wasm build presents one frame of rui::demo::reference_frame through the real browser backend (putImageData onto <canvas id="surface">). Those pixels are read straight back out with getImageData and compared, byte for byte, against the same frame drawn by cargo run -p rui --example parity on this machine. Both sides use the embedded faces, 960×640, scale 1, and a freshly zeroed Memory, so nothing but the backend differs.
