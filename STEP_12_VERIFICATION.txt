========== DEPLOYMENT GUIDE ==========

Prerequisites for Release:
1. GitHub account with repository access
2. crates.io account with API token
3. Rust toolchain (1.85+)

Steps to Release on crates.io:

1. Verify Version:
   cargo bump patch/minor/major  # or manually edit Cargo.toml
   Version should match: 0.1.0 for initial release

2. Verify All Tests Pass:
   cargo test --all-targets       # All platforms
   cargo test --doc               # Documentation examples
   cargo test --test setup        # Rust version + hook

3. Update CHANGELOG (if using one):
   - Document new features
   - Document bug fixes
   - Document breaking changes
   - Reference commits or PRs

4. Create Git Tag:
   git tag -a v0.1.0 -m "Initial release of rui"
   git push origin v0.1.0

5. Publish to crates.io:
   cargo publish                  # Publishes current version

6. Verify Publication:
   - Check crates.io for new version
   - Verify documentation renders correctly
   - Test installation: cargo new test_app && cargo add rui

Post-Release:

1. Create GitHub Release:
   - Tag: v0.1.0
   - Title: "Release 0.1.0"
   - Description: Major features, breaking changes

2. Announce Release:
   - Rust forum
   - Reddit r/rust
   - Twitter/social media
   - Email to users

3. Monitor Issues:
   - Watch for bug reports
   - Respond to feature requests
   - Plan next release
